A: Inline Edit

Badges direkt in der StatusBar bearbeiten. Drag zum Sortieren, X zum Ausblenden, + zum Hinzufuegen. Klick auf Badge oeffnet Config (z.B. Wetter: Anzahl Stunden).

B: Popup / Sheet

Klick auf Edit-Icon in der StatusBar oeffnet ein Popup mit der Badge-Liste. Toggles, Drag-Sortierung, und pro Badge konfigurierbare Optionen (z.B. Anzahl Stunden). Sauberer, mehr Platz fuer Optionen.
